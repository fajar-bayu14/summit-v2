## Rules already loaded (don't duplicate)

## App architecture (backend)
- Controllers grouped by role: `app/Http/Controllers/{Admin,Mitra,Pendaki}/`.
- All API routes in `routes/api.php`, guarded by `auth:sanctum` + `role:` / `kyc.verified` middleware aliases (defined in `bootstrap/app.php`).
- Auth = Sanctum Bearer token + email OTP (`register`/`login`/`verify-otp`/`resend-otp`; login/resend throttled).
- Every controller endpoint is annotated with `OpenApi\Attributes` (`#[OA\Post]`) for l5-swagger; UI at `/api/documentation`, regenerate with `php artisan l5-swagger:generate` (outputs to `storage/api-docs/`).
- Responses use the `{status, message, data[, errors]}` envelope; all `api/*` exceptions render as JSON with Indonesian messages, centralized in `bootstrap/app.php`.
- Follow existing patterns: Form Requests (`app/Http/Requests/`), API Resources (`app/Http/Resources/`), Policies, and `decimal:2` money casts; business logic in `app/Services/`.

## API prefix & naming (verified via `php artisan route:list`)
- All routes are under `/api/v1` — set globally by `apiPrefix: 'api/v1'` in `bootstrap/app.php`, so `routes/api.php` paths show no `/v1` but the real URLs do (e.g. `POST /api/v1/auth/register`). **Do not drop the `/v1`** — it 404s.
- Paths are English (`/auth/*`, `/mountains`, `/products`, `/orders`, `/cart`, `/kyc`); only route NAMES are Indonesian (`gunung.index`, `pesanan.store`). PRD spec (`docs/prd/technical-specs/api-standards.md`) matches this, so no migration needed.
- Mobile API base is `http://localhost:8000/api/v1` (`src/api/http.js`; override via `VITE_API_BASE_URL`).

## Commands: backend (workdir `backend/`)
- Setup: `composer run setup` (install, .env, key, migrate, npm build)
- Dev: `composer run dev` (artisan serve + queue:listen + vite); assets only: `npm run dev` / `npm run build`
- Tests: `composer test` or `php artisan test --compact [--filter=...]`; Pest, files mirror controllers under `tests/Feature/{Admin,Mitra,Pendaki}/`, in-memory sqlite (phpunit.xml) with per-file `LazilyRefreshDatabase`
- Format: `vendor/bin/pint --dirty`
- Seeded admin: `admin@example.com` / `password`

## Commands: mobile (workdir `mobile/`)
- Package manager is **pnpm** (README + `pnpm-workspace.yaml`); `node_modules` is already installed. Run: `pnpm install`, `pnpm dev` (quasar dev, opens browser), `pnpm build` (quasar build).
- Lint/format are **oxlint + oxfmt** (NOT eslint/prettier): `pnpm lint` (fix) and `pnpm lint:check`. Config: `.oxlintrc.json` (max 10 warnings, correctness=error) + `.oxfmtrc.json` (no semicolons, single quotes, `arrowParens: avoid`, printWidth 80). VS Code formats with the Oxc extension.
- Routing is **filename-based** (`build.filenameBasedRouting: true`, hash mode): routes map to files in `src/pages/`; `index/(index).vue` = `/`, `index/second.vue` = `/second`, `[...path].vue` = 404. Files live under `src/pages/` (or `src/pages/index/`). `src/router/index.js` + `.quasar/` (generated by `postinstall: quasar prepare`) wire this up — don't hand-edit the auto-routes.
- `postinstall` runs `quasar prepare`, which regenerates `.quasar/` (ignored dir); `jsconfig.json` extends `.quasar/tsconfig.json`.
- Brand design system lives in `DESIGN.md` (primary `#1E3A2B` deep forest green, secondary `#E65100` orange, Inter, 8px grid, 16px mobile margins, 44px touch targets) but is **NOT applied yet** — `src/css/quasar.variables.scss` still has default Quasar colors and pages are the starter template. Follow DESIGN.md when building real screens.
- `mobile/opencode.json` configures the Stitch MCP; skills in `mobile/.opencode/skills/` (design, brand, ui-styling, etc.) auto-load for UI work.
- Node `>= 22.12` required (package.json engines).
